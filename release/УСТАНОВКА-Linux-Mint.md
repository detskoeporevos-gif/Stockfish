# GambitFish на Linux Mint — установка и запуск

Гайд для готового пакета `gambitfish-flask.tar.gz`. Проверено на Linux Mint 21/22
(и на любом Ubuntu 22.04+). Всё работает локально: интернет после установки
не нужен, движок считается в WASM прямо на вашем компьютере.

---

## 0. Что в пакете

```
gambitfish/
├── start.sh              ← запуск в один шаг
├── gambitfish.html       ← автономная версия: двойной щелчок, без сервера
├── README.md             ← описание движка и API
├── УСТАНОВКА.md          ← этот файл
├── server/app.py         ← Flask-сервер (статика + JSON API)
├── server/requirements.txt
├── web/                  ← интерфейс: index.html, src/, assets/, vendor/, public/gambitfish.wasm
└── node/bridge.mjs       ← мостик Python → WASM-движок
```

Две версии:

| | как запускать | что нужно |
|---|---|---|
| **Автономная** | открыть `gambitfish.html` двойным щелчком | только браузер |
| **Через Flask** | `./start.sh` | python3 + node |

---

## 1. Ставим зависимости (один раз)

Откройте терминал (Ctrl+Alt+T) и выполните:

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip nodejs npm
```

Проверьте версии:

```bash
python3 --version     # нужен 3.9 или новее
node --version        # нужен 18 или новее
```

> В Mint 21 стоит Node 12–16. Если `node --version` показывает меньше 18,
> поставьте свежий Node:
> ```bash
> curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
> sudo apt install -y nodejs
> ```

---

## 2. Распаковываем и запускаем

```bash
# перейдите туда, где лежит архив (обычно ~/Загрузки / ~/Downloads)
cd ~/Загрузки
tar -xzf gambitfish-flask.tar.gz
cd gambitfish

chmod +x start.sh
./start.sh
```

Скрипт сам:
1. найдёт `python3` и `node`;
2. создаст локальное окружение `.venv` и поставит туда Flask;
3. поднимет сервер и напечатает адрес:

```
→ GambitFish: http://127.0.0.1:5000
  (остановить — Ctrl+C)
```

Откройте в браузере **http://127.0.0.1:5000** — увидите доску с фигурами,
чат комментатора, вкладки «Гамбиты», «Разбор PGN» и «Настройки».

Другой порт:

```bash
./start.sh 8000        # или: PORT=8000 ./start.sh
```

Запуск в фоне (сервер продолжит работать после закрытия терминала):

```bash
nohup ./start.sh 5000 > gambitfish.log 2>&1 &
# остановить:  pkill -f "server/app.py"
```

Доступ с телефона в той же Wi-Fi-сети: сервер слушает `0.0.0.0`,
поэтому откройте `http://<IP-компьютера>:5000` (IP: `ip a` → `inet 192.168…`).

---

## 3. Проверка, что всё живо

```bash
curl http://127.0.0.1:5000/health
# {"node":true,"ok":true,"version":"1.0","wasm":true}
```

Разбор партии из командной строки:

```bash
curl -s -X POST http://127.0.0.1:5000/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{"pgn":"1. e4 e5 2. f4 exf4 3. Nf3 g5 4. Bc4 g5g4","movetime":300}' | head -c 600
```

Ответ — JSON с отчётом, метками по каждому полуходу, точностью и индексом
авантюрности.

## 4. Автономная версия (без сервера вообще)

```bash
xdg-open gambitfish.html
```

Или двойной щелчок по файлу в файловом менеджере. Внутри уже лежит
и движок (WASM, base64), и фигуры, и стили — один файл ~508 КБ.
Можно скопировать на флешку или отправить по почте: работает офлайн,
ничего не устанавливает и не требует Node/Python.

## 5. Если что-то не так

| Симптом | Что делать |
|---|---|
| `python3-venv is not installed` | `sudo apt install python3-venv` |
| `Не найден node` | `sudo apt install nodejs npm`, при старом Node — см. п. 1 |
| `Address already in use` | занят порт: `./start.sh 8001` |
| Страница открылась, но доска пустая | нажмите Ctrl+Shift+R (жёсткая перезагрузка кэша) |
| В браузере «WASM не загрузился» | откройте `http://127.0.0.1:5000/health` — если `wasm:false`, файл `web/public/gambitfish.wasm` не распаковался, распакуйте архив заново |
| Движок думает долго | вкладка «Настройки» → «Время на ход» поставьте 0.3–0.8 с |
| Хочется совсем без Python | пользуйтесь `gambitfish.html` |

## 6. Как это устроено (коротко)

* **Движок** — свой C-движок (`engine/`), собранный в WebAssembly
  (`web/public/gambitfish.wasm`, ~130 КБ). Поиск с альфа-бета отсечениями,
  нулевым окном, SEE, ходами-убийцами и историей; ~1.2 млн узлов/с в браузере.
* **Книга гамбитов** — 44 гамбита, 167 линий, 345 позиций; встроена в WASM.
* **Комментатор** — шаблонный генератор с тысячами комбинаций фраз, но
  привязанный к фактам позиции (жертва, SEE, поле, угрозы, инициатива).
* **Интерфейс** — ванильный ES-модульный JS + `cm-chessboard` (MIT)
  и SVG-фигуры Cburnett (CC BY-SA 3.0), вендорены в `web/vendor`, `web/assets`.
* **Flask** — только статика и JSON API; вся тяжёлая работа в WASM,
  Python-процесс запускает `node/bridge.mjs` и возвращает результат.

Подробности, API и список гамбитов — в `README.md`.
